channel-autopilot

channel-autopilot is an open-source tool that produces and uploads educational science and technology explainer videos to a single YouTube channel owned by its developer.

It uses the YouTube Data API and YouTube Analytics API, authorised only by the channel owner, to upload videos, set thumbnails and read the channel's own analytics. It is not offered to other users and does not request access to anyone else's account.
