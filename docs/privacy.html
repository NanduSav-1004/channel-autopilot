Privacy Policy

Last updated: 20 October 2026

channel-autopilot is a personal automation tool run by its developer for one YouTube channel that the developer owns. It has no other users.

What the app accesses

With the developer's own authorisation, the app uses these Google permissions on the developer's own YouTube channel only:

  • youtube.upload and youtube: to upload videos and set their titles, descriptions, thumbnails and chapters.
  • yt-analytics.readonly: to read the channel's own performance statistics so future videos can be improved.

What is collected and stored

The app does not collect personal information from visitors or viewers. The only credential it stores is the developer's own OAuth refresh token, kept in encrypted GitHub Actions secrets and on the developer's own computer. Channel analytics are used only to guide the developer's own content decisions.

Sharing

No Google user data is sold, shared with or transferred to any third party, and none is used for advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised as an issue at github.com/NanduSav-1004/channel-autopilot/issues.
